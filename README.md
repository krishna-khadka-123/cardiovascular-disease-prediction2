A cardiovascular disease risk assessment web application built using HTML, CSS, JavaScript, and a Logistic Regression machine learning model.

## Features

- Cardiovascular disease risk prediction
- Logistic Regression machine learning model
- StandardScaler feature scaling
- Patient input interface
- Confusion matrix
- Classification report
- Accuracy and model performance metrics
- Browser-based prediction

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
- JSON

## Machine Learning

The model uses Logistic Regression with:

- StandardScaler
- Balanced class weights
- Train/test split
- Classification report
- Confusion matrix

## Disclaimer

This project is for educational and demonstration purposes only. It is not a medical diagnostic tool.
